📦 Bindings
The project covers 9 key bindings that make up 90% of Swift syntax:

Binding	Name	What it gives
1️⃣	Types & Containers	enum, struct, protocol
2️⃣	Data Safety	guard, if let, optionals
3️⃣	Logic & Branching	switch, where, case let
4️⃣	Collections & Transformation	filter, map, reduce, sorted
5️⃣	Code Structuring	extension, mutating, inout
6️⃣	Errors & Handling	throws, do-catch, enum Error
7️⃣	Memory Management	weak, unowned, [weak self]
8️⃣	Data Flow	closure, @escaping
9️⃣	Clean Code	MARK:, Access Control, final
🚀 How to Use
Open SwiftBindings.swift in your project.

Run the program in the console.

Use the built-in functions:

showBinding(for: "enum") — search by name

showAllCategories() — view all categories
